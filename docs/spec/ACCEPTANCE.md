# Acceptance Matrix

| ID | Check | Command or test | Pass condition |
| --- | --- | --- | --- |
| AC-API-01 | Request model bounds | `pytest -q tests/test_contracts.py` | invalid enum, empty query, and out-of-range top_k are rejected |
| AC-API-02 | Core endpoint shape | `pytest -q tests/test_api_smoke.py` | health, ask, search, documents, and KB status return expected keys |
| AC-DATA-01 | Artifact fields | `python -m jinrong.cli path-audit` plus JSONL schema check | no illegal persisted paths; required IDs and hashes exist |
| AC-DATA-02 | Empty/null semantics | contract tests and fixture review | absent metadata is `null`, empty collections are `[]`, unknown status is `unknown` |
| AC-EVAL-01 | Trusted read-only endpoints | API smoke with missing report fixture | missing report is explicit `available: false` |
| AC-EVAL-02 | Independent holdout gate | `pytest -q tests/test_eval_holdout.py` and reviewed freeze manifest | no dev overlap; at least five distinct cases per category; complete answer/evidence gold; named external review with timezone |
| AC-EVAL-03 | Bound final scoring | `python -m jinrong.cli eval-acceptance ...` | ready gate and matching holdout SHA-256; all five competition metrics pass; report includes provenance and latency |
| AC-REPRO-01 | Relocation | P0-A isolated rebuild | 500 inputs, zero build errors, deterministic core artifact hashes |
| AC-COMP-01 | Competition quality targets | independently versioned holdout run | targets in the competition brief are met and report has run ID/input fingerprint |

Historical reports and pre-gate A/B runs are diagnostic evidence only until generated by a named acceptance run.
